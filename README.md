# SkyWings - Flight Search & Reservation System

A clean, responsive, and interactive Flight Search & Booking web application developed using pure HTML5, CSS (TailwindCSS CDN), and Vanilla JavaScript.

## 🚀 Features
- **Smart Flight Search**: Search scheduled flights between major domestic airports (Delhi, Mumbai, Bangalore, Goa, Hyderabad, etc.).
- **Timing Categories**: Filter flights by Morning (6 AM - 12 PM) and Evening & Night schedules.
- **Dynamic Sorting**: Sort flight results by Lowest Price, Highest Price, Fastest Duration, and Earliest Departure.
- **User Authentication**: Sign In & Register system with session management using browser LocalStorage.
- **Flight Reservation**: Clean passenger booking modal to confirm reservations with auto-generated PNR / Reference codes.
- **Bookings Management**: View confirmed tickets with passenger details and cancel bookings with a confirmation modal.
- **Fully Responsive**: Mobile-friendly and clean interface.

## 📂 Project Structure
```
├── index.html       # Main Flight Search & Booking Portal
├── login.html       # User Sign In & Registration Page
├── functions.js     # Core JavaScript logic & Flight Database
└── README.md        # Project documentation
```

## 🛠️ Getting Started
Simply open `index.html` or `login.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, etc.). No build tools or backend servers required!
